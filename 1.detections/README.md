# 1. Detections 

## 🎯 Purpose
This section explains the fundamentals of detection engineering for SOC Analysts (L1).  
It covers the theory behind detection rules, why they matter, and how they are used in real SOC environments.


- how detection rules work (Sentinel, Elastic, Sigma)
- how MITRE ATT&CK maps to detection logic
- how to identify suspicious behaviour in logs
- how to write basic detection rules
- how to validate detections with real evidence

Each subfolder contains:
- theory 
- examples 
- evidence  (based on hands-on practice)

This structure ensures I learn both the **concepts** and the **practical skills** required for SOC L1.
