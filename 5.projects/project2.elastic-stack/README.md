# Elastic Stack Lab Environment

## Objective
Create a learner‑friendly Elastic Stack environment to practice EQL detections, log analysis and host-based telemetry review.

## Setup
- Elasticsearch  
- Kibana  
- Beats (Winlogbeat with Sysmon integration)

## Activities Performed
- Simulated LSASS access attempts  
- Executed suspicious PowerShell and script activity  
- Generated authentication anomalies for triage practice

## Logs Generated
- Process events  
- Script execution logs  
- Authentication logs

## Outcome
Elastic telemetry was used to validate EQL rules, explore detection logic and support hands-on investigation workflows.
