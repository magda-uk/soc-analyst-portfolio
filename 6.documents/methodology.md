# SOC Analysis Methodology

### 1. Detection
Identify suspicious behaviour using SIEM rules.

### 2. Triage
Assess severity, context and potential impact.

### 3. Investigation
Correlate logs, review processes, analyse behaviour.

### 4. Containment
Prevent further malicious activity.

### 5. Eradication
Remove malicious artefacts.

### 6. Recovery
Restore systems to normal operation.

### 7. Lessons Learned
Document findings and improve detections.
