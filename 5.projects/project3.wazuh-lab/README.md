# Wazuh Lab Environment

## Objective
Set up a learner‑friendly Wazuh environment to practice host-based detection, log collection and rule validation.

## Setup
- Wazuh Manager  
- Wazuh Agent on Windows VM  
- Sysmon integrated with Wazuh

## Activities Performed
- Simulated suspicious PowerShell activity  
- Generated network scanning behaviour  
- Executed scripts via WScript and CScript to observe telemetry differences

## Logs Generated
- Process creation  
- Script execution  
- Network activity

## Outcome
Wazuh telemetry was used to validate Sigma and Elastic-compatible detections and to understand host-based monitoring workflows.
