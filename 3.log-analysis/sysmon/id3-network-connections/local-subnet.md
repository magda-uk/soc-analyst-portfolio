# Sysmon Event ID 3 Local Subnet IPv6 DNS Resolution (VS Code)

## 🔸 Summary
This case analyses a **Sysmon Event ID 3 (`Network Connection Detected`)** event capturing outbound UDP traffic on port 53. 
While external, unmanaged DNS queries can sometimes mimic command-and-control beaconing or tunneling attempts, architectural and network-prefix validation confirms this is a **benign local subnet IPv6 DNS resolution** generated by VS Code during standard extension and runtime operations. **This provides a practical example for technical interviews on why a port 53 connection initiated by a user executable can be entirely benign once the destination subnet is verified.**

## 🔸 Technical Analysis & Process Lineage

⚙️ **Network Subnet & Transport Context**
* **Subnet Alignment:** The source host and destination resolver share an identical `/64` IPv6 network prefix (`2a0a:ef40:144a:a601::/64`), confirming internal communication with the local default gateway or local DNS forwarder.
* **Transport Behaviour:** Utilises standard UDP port 53 for recursive DNS lookups initiated by the application runtime.

⚙️ **Application Architecture (Chromium/Node.js Networking)**
* **Asynchronous Resolver:** Modern Electron applications (such as VS Code) leverage asynchronous network stacks that issue direct socket queries to configured local DNS servers to fetch extension dependencies, language servers, and service updates.

⚙️ **Threat Hunting & Interview Context ([MITRE ATT&CK T1071.004](https://attack.mitre.org/techniques/T1071/004/))**
* **Network Egress Inspection:** Direct UDP 53 traffic directed at unmanaged external public infrastructure can signify malicious command-and-control communication or DNS tunnelling.
* **Technical Justification:** This scenario serves as an exceptional practical example for technical interviews to justify why an outbound port 53 connection from a user-space executable is entirely benign upon verifying the local destination subnet.

## 🔸 Benign Triage Criteria (False-Positive Validation)

* ☑️ **Trusted Application Path:** Initiated from the canonical user-space path for Microsoft VS Code.
* ☑️ **Local Subnet Scope:** Destination resolver is contained within the identical local `/64` IPv6 network prefix.
* ☑️ **Standard Port Utilisation:** Operates over conventional UDP port 53 without unauthorised tunnelling characteristics.
