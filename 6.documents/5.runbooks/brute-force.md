# Brute Force Runbook

## 1. Detection
- Multiple failed logins.
- Suspicious IP ranges.

## 2. Triage
- Validate user behaviour.
- Check MFA logs.

## 3. Investigation
- Review successful logins.
- Check post‑authentication activity.

## 4. Response
- Block IP.
- Reset credentials.
- Enforce MFA.

## 5. Lessons Learned
- Improve authentication anomaly detection.
- Add IP ranges to watchlist.
