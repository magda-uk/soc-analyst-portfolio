# Incident Response Workflow

This workflow describes the end‑to‑end process for handling security incidents in a SOC environment.

---

## 1. Detection
- Alert triggered by Sentinel, Elastic, Sigma or custom KQL.
- Analyst validates alert context.
- Severity assigned using SOC severity framework.

---

## 2. Triage
- Identify affected user, device, IP.
- Check authentication patterns.
- Validate process execution.
- Determine if alert is false positive or requires investigation.

---

## 3. Investigation
- Build timeline using hunting queries.
- Pivot across logs: auth, process, network, scriptblocks.
- Identify root cause and attack vector.
- Validate persistence or lateral movement.

---

## 4. Containment
- Disable compromised accounts.
- Isolate affected devices.
- Block malicious IPs or domains.
- Revoke tokens or sessions.

---

## 5. Eradication
- Remove malware or tools.
- Clean registry or scheduled tasks.
- Patch vulnerabilities.
- Reset credentials.

---

## 6. Recovery
- Restore systems.
- Re-enable accounts.
- Monitor for re‑infection.
- Validate normal behaviour.

---

## 7. Lessons Learned
- Document incident.
- Update detections.
- Improve playbooks.
- Share findings with engineering teams.
