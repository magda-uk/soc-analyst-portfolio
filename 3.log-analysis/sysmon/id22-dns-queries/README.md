# Sysmon Event ID 22. DNS Query Analysis

Sysmon Event ID 22 records DNS query activity performed by processes on the endpoint.  
This directory contains three complementary analyses covering WPAD behaviour, OEM telemetry, and application‑driven DNS lookups.  
Together, they demonstrate practical triage, baseline identification, and correct SOC classification.

---

## 1) WPAD Query Analysis  
**File:** `sysmon-22-wpad-analysis.md`  
WPAD (Web Proxy Auto‑Discovery) generates periodic DNS lookups as part of Windows proxy discovery.  
These queries are common in both enterprise and home environments.  
**Classification:** Benign baseline.

---

## 2) Lenovo OEM Telemetry  
**File:** `Event-iD-22-lenovo.md`  
Lenovo devices perform DNS lookups related to OEM services, update checks, and telemetry.  
This behaviour is expected and forms part of the normal endpoint baseline.  
**Classification:** Benign baseline.

---

## 3) Visual Studio Code (code.exe) DNS Queries  
**File:** `Event-22-code-exe.md`  
Visual Studio Code performs DNS queries for extensions, updates, remote services, and telemetry.  
These lookups depend on user activity and application state.  
**Classification:** Benign contextual activity.

---

## SOC Triage Summary

| Source | Behaviour | Classification |
|--------|-----------|----------------|
| WPAD | Proxy auto‑discovery | Baseline |
| Lenovo OEM | Device telemetry | Baseline |
| VS Code | Application activity | Contextual benign |

None of the analysed cases indicate malicious behaviour.  
All represent legitimate DNS activity generated by the operating system or trusted applications.

---

## MITRE ATT&CK Context

DNS can be abused for command‑and‑control or exfiltration  
(**T1071.004 — Application Layer Protocol: DNS**).  
However, the events documented here do **not** exhibit patterns associated with adversarial use.

---

## Purpose

This directory provides practical examples of how a SOC analyst evaluates DNS telemetry by separating:

- baseline noise  
- legitimate application behaviour  
- OEM artefacts  
- environmental queries  
- potential misconfigurations  

It serves as a reference for accurate triage of Sysmon Event ID 22.
