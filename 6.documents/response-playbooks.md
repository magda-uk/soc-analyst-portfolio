# Response Playbooks

## Suspicious PowerShell Execution
- Review command line.
- Check parent process.
- Investigate downloads.
- Isolate host if malicious.

## Credential Dumping
- Check LSASS access.
- Review authentication logs.
- Reset credentials.
- Investigate privilege escalation.

## Anomalous Authentication
- Review IP reputation.
- Check MFA logs.
- Reset password.
- Monitor for further attempts.
