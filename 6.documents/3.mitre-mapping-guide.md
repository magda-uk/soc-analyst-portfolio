# MITRE ATT&CK Mapping Guide

This guide explains how detections, investigations and hunting queries are mapped to MITRE ATT&CK techniques.

---

## 1. Why MITRE Mapping Matters
- Provides standardised classification.
- Helps analysts understand attacker behaviour.
- Supports reporting and compliance.
- Improves detection coverage.

---

## 2. Mapping Rules
- Each detection must map to at least one technique.
- Hunting queries may map to multiple techniques.
- Investigations should reference techniques observed.

---

## 3. Examples from This Portfolio

### Authentication Anomalies
- **T1078 — Valid Accounts**
- **T1110 — Brute Force**

### PowerShell Encoded
- **T1059.001 — PowerShell**

### LSASS Access / Credential Dumping
- **T1003 — OS Credential Dumping**

### Suspicious PowerShell (Sigma)
- **T1059 — Command and Scripting Interpreter**

---

## 4. Mapping Format
Use this structure in detections:

tactics:

    Execution techniques:

    T1059.001

---

## 5. Continuous MITRE Review
- Update mappings when techniques evolve.
- Add sub‑techniques when applicable.
- Review coverage quarterly.
