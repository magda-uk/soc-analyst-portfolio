This repository showcases my technical capabilities as a Security Operations Centre (SOC) Analyst. It contains practical examples of detection engineering, log analysis, KQL queries, and documentation that reflects my investigative approach and understanding of adversary behaviour.

---

## 🎯 Objective

To demonstrate my readiness for a SOC Analyst (L1) role through hands‑on work, structured analysis, and clear documentation of my investigative process.

---

## 📂 Repository Structure

### **detections/**
Detection rules written in Sigma, Microsoft Sentinel (KQL), and Elastic.  
Each rule includes context, rationale, validation steps, and MITRE ATT&CK mapping.

### **log-analysis/**
Realistic investigations based on Windows Events, Sysmon logs, Azure AD activity, and simulated attacks.

### **kql/**
A collection of KQL queries for triage, hunting, anomaly detection, and correlation within Microsoft Sentinel.

### **projects/**
Small labs and practical environments built to generate logs, simulate attacks, and validate detections.

### **docs/**
Methodology, triage checklist, response playbooks, and supporting documentation.
