# Phishing Runbook

## 1. Detection
- User reports suspicious email.
- Alert triggered by anti‑phishing rule.

## 2. Triage
- Check sender domain.
- Inspect URLs.
- Validate attachments.

## 3. Investigation
- Review user activity.
- Check if credentials were used post‑email.
- Validate MFA logs.

## 4. Response
- Block sender domain.
- Reset user credentials.
- Notify user.

## 5. Lessons Learned
- Update anti‑phishing rules.
- Add domain to blocklist.
